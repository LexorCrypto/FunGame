# FunGame — PISSUARIUS

Аркадный шутер в стиле Galaxian (80-е) с осовремененной 16-битной графикой.

Галактика Pissuarius: космический корабль против туалетов, каках, тараканов и писсуаров.
Босс каждые 5 волн: супер-туалет, большая макака, супер-какаха.

## Играть

https://lexorcrypto.github.io/FunGame/

## Управление

WASD или стрелки — движение, Пробел — огонь.

## Статус

PRD (концепт и архитектура): `docs/PRD.md`. Спецификация (числа, волны, спрайты,
аудио): `docs/SPEC.md`. Глоссарий: `CONTEXT.md`. Лендинг: `landing/` (Next.js +
Zustand + Tailwind).

Конвейер: **PRD → спецификация → атомарные задачи → код** (PRD и спецификация готовы).
Задачи и лейблы — планируются в Linear (экспериментально, подключение в работе).

Всё аудио (SFX и музыка) генерируется офлайн через ElevenLabs API и коммитится как
статические ассеты (ключ передаётся только через переменную окружения `ELEVENLABS_API_KEY`,
см. `.env.example`; ключ никогда не попадает в репозиторий и в клиентский код).
