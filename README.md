# FunGame — PISSUARIUS

Аркадный шутер в стиле Galaxian (80-е) с осовремененной 16-битной графикой.

Галактика Pissuarius: космический корабль против туалетов, каках, тараканов и писсуаров.
Босс каждые 5 волн: супер-туалет, большая макака, супер-какаха.

## Играть

https://lexorcrypto.github.io/FunGame/

## Управление

WASD — движение, Пробел — огонь.

## Статус

Готовится PWD — детальный план реализации (`docs/PLAN.md`), затем спецификация.
Код игры будет написан позже по этим документам.

Звуковые эффекты генерируются офлайн через ElevenLabs API и коммитятся как статические
ассеты (ключ передаётся только через переменную окружения `ELEVENLABS_API_KEY`,
см. `.env.example`; ключ никогда не попадает в репозиторий и в клиентский код).
