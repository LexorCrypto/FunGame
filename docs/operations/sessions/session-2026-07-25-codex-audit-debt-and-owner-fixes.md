## Верификация

Всё — на реальном Phaser 3.90 (локальный phaser + `python3 -m http.server 8177`,
кэш браузера отключён), плюс node-юнит там, где логика чистая:

- **Пауэр-ап:** 36 юнит-проверок (падение/покой/кламп/таймеры/очистка). В браузере: падение
  ровно 60 px/s, покой на y=223 внутри зоны игрока, корабль своим ходом (140 px/s) долетает
  из противоположного угла за 2.9 s и подбирает (`doubleShotMs = 10000`), мигание на ~5.2 s,
  исчезновение после 6.0 s; ставки 0.19 → дроп / 0.21 → нет, 0.50 → shot / 0.85 → shield.
- **Crawl:** RU 19 строк / EN 21, максимальная ширина строки 355 px при `WRAP_WIDTH` 360,
  прокрутка идёт, переключение языка перерисовывает строки и пересчитывает скорость.
- **Пауза:** до Esc движутся пауэр-ап (UpdateList), таймер сцены (Clock) и вражеский снаряд
  (Arcade); после Esc сцена неактивна, оверлей виден, за 1.2 s ни один не сдвинулся;
  повторный Esc возвращает движение всем трём; `Q` уводит в меню; после `game.destroy(true)`
  Esc инертен; два Esc в окне game-over → EndScene не дают ошибок консоли.
- **Жизненный цикл:** босс-волна 5 — после смерти группа `bosses` пуста, спрайта нет в display
  list, слушателей shutdown 18→17; Трон — 4 отродья, убитое и ушедшие за край уничтожены,
  прирост `scene.enemies` 0, повторный `destroy()` идемпотентен; четыре волны подряд —
  `enemies` 0, неактивных 0, display list 83 против 91 на старте.
- **Модификаторы цикла:** c=0 → sway 2.5 s / веер 90 px/s; c=1 → 2.25 s / 99; c=3 → 1.823 s / 120;
  c=9 → sway упирается в минимум 1.4 s; фаза 2 на цикле 2 → 142 px/s = 90×1.3×1.1².
- **Аудио:** разрыв петли по `decodeAudioData` в Chrome (тихий хвост + тихое начало, оба канала):
  title 535 → 8.1 ms, battle 2213 → 12.2 ms, при нетронутом boss 11.3 ms; скачок амплитуды на
  стыке ≤ 0.00015 из 1.0; 22/22 файла в кэше, ноль 404.
- **Регресс:** `node --check` по всем изменённым JS, `node scripts/validate_sprites.mjs` — 23 спрайта,
  `--dry-run` генератора печатает фактические 0.5s. Ноль ошибок консоли во всех прогонах.

## Грабли, которые стоит помнить

- `physics.add.group().add(sprite)` обнуляет скорость тела — см. пауэр-ап выше.
- Настоящая заморозка мира — только `scene.pause()`: ручная остановка физики, часов и твинов
  не трогает UpdateList (preUpdate спрайтов, анимации).
- `ffmpeg silencedetect` по умолчанию считает тишиной только момент, когда молчат ВСЕ каналы:
  первая обрезка лупов пропустила 70 ms, потому что мерили по одному каналу.
- Уничтожать члена группы из overlap-колбэка нельзя — Arcade в этот момент обходит группу;
  уборка вынесена в начало `update()`.
