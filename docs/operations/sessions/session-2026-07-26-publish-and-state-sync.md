## Урок

**`main_sha` выводить из `origin/main`, а не из локального HEAD.** Порядок: `git fetch origin`
→ убедиться, что `git rev-list --left-right --count origin/main...HEAD` даёт `0 0` → сверять
полными SHA (`git rev-parse origin/main` против `git rev-parse HEAD`) → записывать в поле
короткую форму, `git rev-parse --short=7 origin/main`: 7 символов — конвенция этого
машинного блока, полный SHA нужен только для сверки. Иначе STATE указывает на коммит,
которого нет ни у кого, кроме этой машины: валидатор такое пропускает — форма SHA корректна,
а достижимость на remote он не проверяет, — и расхождение всплывает только при следующем
старте.
