- **[P2] [CLAUDE.md:94](/Users/aleksejsupilin/Documents/GitHub/Pisuarius/CLAUDE.md:94)** — `back="$tmp.back"` создаётся обычным редиректом, а не через `mktemp`. В общем `/tmp` локальный пользователь может заметить имя `$tmp`, заранее создать `$tmp.back` с открытыми правами либо как symlink; `umask` не меняет права существующего файла, а `>` следует по ссылке. Обернуть блок в `( ... )`, чтобы область действия `umask`, trap и файлов совпадала с процедурой. **Вердикт: edge-case и утечка состояния/временных ресурсов.**
