## Findings (verbatim)

## Находки

- [P1] `scripts/generate_audio.mjs:70` — шесть SFX отправляются с `duration_seconds` 0.2–0.4, тогда как API принимает минимум 0.5 секунды. Полная генерация гарантированно завершится с шестью HTTP 422 и не создаст все 22 файла. Это также нарушает указание SPEC §12 использовать ближайший допустимый эквивалент. [Документация ElevenLabs](https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert). Исправлено только последующим коммитом `c2ba43e`.

- [P2] `scripts/generate_audio.mjs:192` — обработчик сетевых ошибок охватывает только `fetch()`, но не чтение тела. Если соединение оборвётся после получения HTTP-заголовков, `response.arrayBuffer()` отклонится и прервёт весь batch через верхний `main().catch`, вместо регистрации ошибки и продолжения с оставшимися файлами.

- [P3] `scripts/generate_audio.mjs:92` — проверка MP3 принимает любую трёхбайтовую строку `ID3` и любой трёхбайтовый буфер с `FF E0` как валидный файл. Проверено: `ID3` и `FF E0 00` возвращают `true`. Усечённый ответ с HTTP 200 будет записан как MP3.

- [P3] `scripts/generate_audio.mjs:167` — существующий файл пропускается без проверки содержимого. Нулевой или частично записанный MP3 после прерывания на `writeFile` будет считаться готовым при следующих запусках, а команда завершится успешно. Нужна проверка существующего файла либо атомарная запись через временный файл и rename.
