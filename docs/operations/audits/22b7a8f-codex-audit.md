## Disposition

- **[P2] проверка публикации не fail-closed → ИСПРАВЛЕНО** в `11838f0`: пункт требует, чтобы
  `git remote get-url origin` указывал на `LexorCrypto/FunGame`, чтобы fetch завершился
  успешно (иначе процедура останавливается) и чтобы сверялись полные SHA
  `git rev-parse HEAD^{commit}` = `git rev-parse refs/remotes/origin/main^{commit}`.
  Рекомендованный аудитом `git fetch origin refs/heads/main` **не взят дословно**: без
  destination такой рефспек пишет только `FETCH_HEAD`, а обновление
  `refs/remotes/origin/main` остаётся в лучшем случае оппортунистическим — то есть сверка
  ниже сравнивала бы с тем же устаревшим tracking-ref, от которого защищаемся. Записан
  явный рефспек `+refs/heads/main:refs/remotes/origin/main`. Процедура прогнана вживую:
  fetch exit 0, tracking-ref обновлён, сверка корректно отказала, потому что коммиты
  закрытия сессии ещё не были опубликованы.
- **[P2] `AGENTS.md` одновременно вводил дельты и объявлял их ошибкой → ИСПРАВЛЕНО** в
  `11838f0`: пункт переформулирован как «граница файла» — дельты про запуск самого Codex
  здесь легитимны, ошибкой считается лишь общерепозиторное правило, заведённое в обход
  `CLAUDE.md`.
