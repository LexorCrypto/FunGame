# PRD — Pissuarius (FunGame)

**Назначение документа.** Это концепт и архитектура игры: ЧТО строим и ПОЧЕМУ так.
Точные числа (HP, скорости, кулдауны, очки, таблицы волн, пиксельные схемы спрайтов,
партитура чиптюна, промпты для ElevenLabs) здесь намеренно отсутствуют — они
фиксируются следующим документом, **спецификацией**. Затем работа дробится
на **атомарные задачи**, и только после этого пишется код.

Конвейер: **PRD → спецификация → атомарные задачи → код**.

**Исполнитель** — LLM по этому PRD, спецификации и атомарным задачам. Терминология — строго по
`CONTEXT.md` (волна, акт, формация, пикирование, зона игрока и т.д.).

---

## 1. Видение

Аркадный шутер в духе **Galaxian** (автоматы 80-х), переосмысленный в туалетном
юморе. Галактика **Pissuarius**: космический корабль зачищает её от пришельцев —
туалетов, каках, тараканов и прочей сантехнической нечисти. Каждые пять волн —
босс; после финального босса — бесконечный цикл с секретным боссом.

Графика — **осовремененная 16-битная**: пиксель-арт, но с современным «соком»
(частицы, тряска экрана, плавные твины, параллакс, больше кадров анимации,
чем у предков).

## 2. Тон и юмор

- Дружелюбный туалетный юмор: смешно, не грубо. Без жести и токсичности.
- Юмор в механиках, не только в спрайтах: враги дерутся «в тему» (писсуар
  стреляет струёй, сушка для рук сдувает твои снаряды, сантехник — заклятый
  враг всех туалетов).
- Интерфейс двуязычный: **русский и английский**, переключение в меню
  титульника; выбор сохраняется в localStorage. Все надписи — из словаря
  локализации, ни одной строки в коде.

## 3. Платформа, стек, деплой

| Решение | Выбор | Почему |
|---|---|---|
| Платформа | Браузер | Ноль установки, запуск по ссылке |
| Движок игры | **Phaser 3.90.0** (пин версии) | Готовые сцены/твины/частицы/аудио; зрелое API |
| Подключение игры | CDN jsDelivr, без сборки | Игра — vanilla JS, отдаётся как есть |
| Язык игры | Vanilla JS, ES-модули | Нет шага компиляции, минимум движущихся частей |
| Лендинг | **Next.js 14 + Zustand + Tailwind** (статический экспорт, `landing/`) | Богатый лендинг с анимацией-тизером; собирается в CI |
| Хостинг | GitHub Pages, деплой через **GitHub Actions** | Репо: github.com/LexorCrypto/FunGame (публичный) |
| Страницы | `/` — лендинг → `game.html` — игра | — |

Phaser 4 на момент написания уже существует (4.2.1), но выбран Phaser 3:
максимальная база примеров и лучшая знакомость LLM-исполнителя с API.
Смена версии = одна строка в `game.html`.

## 4. Управление

- **WASD** или **стрелки ←↑↓→** — движение корабля (4 направления); раскладки равнозначны.
- **Пробел** — огонь.
- **Esc** — пауза. **M** — вкл/выкл звук.
- Управление только клавиатурное (десктоп). Тач-ввод — вне скоупа.

## 5. Игровое поле и рендер

- Логическое разрешение **480×270 (16:9)**, горизонтальное поле.
- Рендер pixel-art: без сглаживания, целочисленное масштабирование,
  `Phaser.Scale.FIT` + центрирование — поле впишется в любой экран.
- Фон — звёздное небо с параллаксом (несколько слоёв, разная скорость).
- Сверху — **формация** врагов, снизу — **зона игрока** (нижняя треть поля).

## 6. Игровые состояния

```
Boot → Title → Crawl → Game (волны и боссы) → GameOver → Title
                          │
                          └→ Victory → Endless (бесконечный цикл) → GameOver
```

- **Boot** — построение текстур из пиксельных схем, загрузка аудио.
- **Title** — название, «INSERT COIN», таблица рекордов, выбор языка.
- **Crawl** — заставка-пролог в духе Звёздных Войн: жёлтый текст уходит вверх
  под эпичную 8-битную увертюру; предыстория галактики, читается меньше минуты,
  пропускается (Пробел, Esc или клик). Тексты — в спецификации.
- **Game** — волны, боссы, переходы между актами.
- **GameOver** — очки, ввод в таблицу рекордов.
- **Victory** — победа над Пессимарио, переход в бесконечный цикл.
- Пауза по Esc поверх Game.

## 7. Поле боя

- **Формация** висит в верхней части поля и покачивается как единое целое
  (классический «дыхание влево-вправо» Galaxian).
- Враги отрываются от формации и **пикируют** в зону игрока по паттерну
  своего типа; уцелевшие возвращаются в строй.
- **Корабль** свободно движется в зоне игрока (нижняя треть поля) — WASD
  используется полностью: уклонение от пикирования и снарядов.
- Столкновения: снаряды игрока ↔ враги/боссы; снаряды врагов и тела врагов ↔ корабль.

## 8. Враги (8 типов)

Четыре базовых + четыре добавленных. Числа (HP, скорости, очки) — в спецификации.

| Тип | Роль | Паттерн пикирования (концепт) |
|---|---|---|
| **Таракан** | Давление | Быстрый зигзаг, трудно прицелиться |
| **Писсуар** | Огонь | Пикирует и стреляет струёй-снарядом |
| **Какаха** | Контроль площади | Падает вниз и взрывается лужей — зона поражения на месте приземления |
| **Туалет** | Танк | Живучий, медленное пикирование с атакой смывом |
| **Ёршик** | Камикадзе | Летит в корабль напрямую, вращаясь; не стреляет |
| **Вантуз** | Дебафф | Стреляет присоской: прилипает к кораблю и ненадолго замедляет его |
| **Плесень** | Приоритет целей | Если не убить быстро — делится надвое |
| **Сушка для рук** | Контроль огня | Зависает и сдувает снаряды игрока в сторону; сама не атакует |

## 9. Боссы (5 + секретный)

У каждого босса **две фазы**: при падении HP ниже порога — новая атака и рост
темпа. Концепты атак (параметры — в спецификации):

1. **Супер-Туалет** (акт 1). Парит в верхней половине, качается.
   Фаза 1: веер капель; «смыв» — воронка, тянущая корабль к центру поля.
   Фаза 2: плотнее веер, дольше смыв, выше темп.
2. **Большая Макака** (акт 2). Прыгает между точками поля, зона приземления
   опасна. Кидает снаряды по дуге.
   Фаза 2: двойные прыжки, гроздья снарядов.
3. **Супер-Какаха** (акт 3). Нависает и плюхается: по зоне игрока бежит
   волна-лужа, в которой есть разрыв — уклоняться через разрыв.
   Фаза 2: брызги при плюхе, волны чаще.
4. **Королева Тараканов** (акт 4). Ползает по верху поля и рожает тараканов,
   которые сразу пикируют. Уязвимое брюхо.
   Фаза 2: рожает чаще и более живучих.
5. **Злой Сантехник Пессимарио** (акт 5, финал). Единственный босс,
   вторгающийся в зону игрока: ходит и прыгает по всему полю.
   Гаечный ключ-бумеранг.
   Фаза 2: вантуз-бур — периодически засасывает снаряды игрока и отражает их.
6. **Золотой Трон** (секретный, только бесконечный цикл). Ротирует атаки
   всех пяти боссов. Самый живучий враг в игре.

## 10. Акты, волны, бесконечный цикл

- **5 актов × 5 волн = 25 волн**; каждая пятая волна — босс вместо формации.
- Каждая волна — **явная запись в данных** (состав формации по типам,
  скорость, частота пикирования и огня). Никакой процедурной генерации:
  баланс детерминирован, таблицы — в спецификации.
- Рост сложности внутри и между актами: шире формация, больше «продвинутых»
  типов (вантуз, плесень, сушка появляются с 2-го акта), выше темп пикирования.
- После победы над Пессимарио — **бесконечный цикл**: волны повторяются
  с нарастающей скоростью; здесь встречается Золотой Трон.

## 11. Живучесть

- 3 жизни. Одно попадание (снаряд или таран) = потеря жизни.
- После респауна — короткая неуязвимость с мерцанием спрайта.
- Жизни кончились → GameOver → таблица рекордов.

## 12. Скоринг

- У каждого типа врага своя цена; **пикирующий враг стоит вдвое больше**,
  чем тот же враг в формации (как в оригинальном Galaxian).
- Бонус за волну, пройденную без потерь.
- Топ-10 рекордов в `localStorage` (без сервера).

## 13. Пауэр-апы

Два, выпадают из убитых пикирующих врагов, подбираются касанием:

- **Двойной выстрел** — удваивает огонь корабля до потери жизни (без таймера).
- **Щит** — поглощает одно попадание.

Индикация активных бонусов — в HUD.

## 14. Визуальный стиль и спрайты

- Все спрайты **генерируются кодом из пиксельных схем**: каждая сущность —
  набор кадров (2–4 на анимацию), каждый кадр — массив строк, где символ =
  цвет палитры. Схемы и палитры — в спецификации.
- Boot-сцена строит из схем текстуры (`generateTexture`), дальше — обычные
  Phaser-анимации. Внешних PNG нет вообще: единый стиль, ноль ассет-файлов.
- «Сок» (обязательная часть стиля): частицы при взрывах, тряска экрана при
  смерти корабля и у боссов, твины при пикировании, мерцание неуязвимости,
  вспышки попаданий.

## 15. Аудио

- **Всё аудио** — и SFX, и музыка — генерируется **офлайн** через ElevenLabs
  и коммитится как статические файлы в `assets/audio/`. Стиль: качественно,
  но в 8-битном ретро-формате. Ключ передаётся только переменной окружения
  `ELEVENLABS_API_KEY`; он никогда не попадает в репозиторий и клиентский код.
  Промпты и параметры — в спецификации.
- **SFX**: выстрел, попадание, взрыв врага, смерть корабля, смыв, струя,
  плюх, фен-свист, бумеранг ключа, пауэр-ап и др.
- **Музыка**: темы титульника, боя, босса, победы, гейм-овер — зацикленные
  8-битные треки; для заставки-пролога — эпичная космооперная увертюра
  в 8-битном стиле (в духе Звёздных Войн).
- M — мьют всего аудио.

## 16. Архитектура кода

Phaser 3.90.0 через CDN в `game.html`; игровой код — ES-модули, без сборки.

```
index.html                  — стартовая страница (готова)
game.html                   — оболочка игры: CDN phaser@3.90.0 + src/main.js
src/main.js                 — конфиг Phaser (480×270, pixelArt, Scale.FIT)
src/scenes/BootScene.js     — построение текстур из схем, загрузка аудио
src/scenes/TitleScene.js    — титульник, таблица рекордов
src/scenes/GameScene.js     — бой: волны, боссы, пауза
src/scenes/CrawlScene.js    — заставка-пролог (текстовый скролл)
src/scenes/EndScene.js      — гейм-овер / победа / вход в бесконечный цикл
src/data/sprites.js         — пиксельные схемы        ← наполняется по спецификации
src/data/waves.js           — 25 волн + параметры боссов ← по спецификации
src/data/i18n.js            — словари RU/EN
src/entities/Player.js      — корабль, движение, огонь, пауэр-апы
src/entities/Enemy.js       — базовый враг + 8 типов
src/entities/Boss.js        — базовый босс + 6 боссов, две фазы
src/entities/Projectile.js  — снаряды обеих сторон
src/entities/PowerUp.js     — двойной выстрел, щит
src/systems/Formation.js    — строй и покачивание
src/systems/DivePatterns.js — паттерны пикирования по типам
src/systems/WaveDirector.js — подача волн из data/waves.js
src/systems/Scoring.js      — очки, бонусы, рекорды localStorage
src/systems/Effects.js      — частицы, тряска, мерцание
src/systems/Audio.js        — загрузка и воспроизведение аудиофайлов, мьют
assets/audio/               — sfx_*.mp3 и music_*.mp3 из ElevenLabs
scripts/generate_audio.mjs  — офлайн-генерация аудио через ElevenLabs API
landing/                    — лендинг (Next.js + Zustand + Tailwind, готов)
.github/workflows/pages.yml — сборка лендинга и деплой на GitHub Pages
```

Принципы: данные отделены от кода (волны/спрайты/музыка — в `data/`);
сущности не знают друг о друге напрямую — взаимодействие через сцену;
каждая система тестируема в изоляции от Phaser-рендера где возможно.

## 17. План этапов для исполнителя

Каждый этап — работающая игра, которую можно открыть и пощупать.
После спецификации этапы дробятся на **атомарные задачи**: одна задача =
одна сессия исполнителя — точные входы (файлы, разделы спецификации),
результат и критерии приёмки.

1. **Скелет**: `game.html`, конфиг, звёздный фон, корабль двигается и стреляет,
   один таракан в формации.
2. **Бой**: формация + пикирование + коллизии + жизни/смерть/неуязвимость.
3. **Ростер**: все 8 типов врагов с их паттернами.
4. **Волны**: WaveDirector, акт 1 целиком, босс Супер-Туалет.
5. **Боссы 2–5**: по одному за итерацию + переходы между актами.
6. **Метагейм**: пауэр-апы, скоринг, HUD, титульник, заставка-пролог,
   гейм-овер, рекорды.
7. **Аудио**: генерация всех файлов через ElevenLabs, подключение к событиям,
   мьют.
8. **Сок и финал**: эффекты, бесконечный цикл, Золотой Трон.
9. **Полировка**: баланс-проход по спецификации, финальная проверка на Pages.

## 18. Что уходит в спецификацию (следующий документ)

- Точные числа: HP врагов и боссов, скорости, кулдауны, тайминги фаз,
  очки по типам, размеры и состав формаций, вероятности пауэр-апов.
- Таблицы всех 25 волн.
- Пиксельные схемы всех спрайтов + палитры.
- Партитура чиптюна (темы по нотам).
- Промпты ElevenLabs для каждого SFX.
